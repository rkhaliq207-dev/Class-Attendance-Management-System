# Class Attendance Management System

## About the Project
This is a beginner-level DSA mini project developed using the C programming language.

The project helps manage student attendance using arrays and singly linked lists.

## Features
- Add new students
- Mark student attendance
- Display attendance reports
- Search students by roll number
- Delete student records
- Calculate attendance percentage
- Check attendance status

## DSA Concepts Used
- Structures
- Arrays
- Singly Linked Lists
- Pointers
- Dynamic Memory Allocation
- Insertion and Deletion
- Linear Searching
- Linked List Traversal

## Technologies Used
- Programming Language: C
- Compiler: GCC
- Code Editor: Visual Studio Code
